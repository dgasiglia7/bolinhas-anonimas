Os vídeos que você adiciona ficam primeiro só neste navegador. Para que todo mundo veja, a página grava o arquivo videos.json direto no repositório do GitHub.

Como criar o token (uma vez só)
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Repository access, escolha Only select repositories e marque este repositório.
  3. Em Permissions → Contents, escolha Read and write.
  4. Gere o token, copie e cole aqui. Ele fica guardado só neste navegador.
