Como funciona a publicação
  1. Você muda os vídeos. Adicionar, editar ou remover vídeos muda só a sua tela, neste navegador. Esses vídeos aparecem marcados como "Não publicado".
  2. Você toca em Publicar. A página envia a lista de vídeos para o GitHub, onde o site fica guardado.
  3. Todo mundo vê. Em cerca de 1 minuto o site atualiza para qualquer pessoa.

devicesCada computador, celular ou navegador é separado. Em cada um que você for usar para publicar é preciso: (1) abrir o site com #/admin no fim do endereço e (2) colar a chave de publicação abaixo. Vídeos não publicados não passam de um computador para outro.

Chave de publicação (token do GitHub)

É uma espécie de senha que só serve para atualizar a lista de vídeos deste site. Ela fica guardada só neste navegador. Em outro computador, cole a mesma chave (se você a guardou) ou crie uma nova.

Não tenho a chave: como criar (leva 2 minutos)

Precisa ser feito entrando no GitHub com a conta dona do site ().

  1. Abra github.com/settings/personal-access-tokens/new e entre na conta, se pedir.
  2. Token name: um nome para lembrar onde vai usar, por exemplo "Bolinhas - notebook".
  3. Expiration: escolha a validade (por exemplo, 1 ano). Quando vencer, a publicação avisa "chave inválida ou expirada" e é só criar outra.
  4. Repository access: escolha Only select repositories e selecione .
  5. Permissions → Repository permissions → Contents: mude para Read and write. Não precisa mexer em mais nada.
  6. Clique em Generate token, copie o código (começa com github_pat_), cole no campo acima e toque em Salvar e testar chave.

shieldO GitHub mostra a chave só uma vez. Se quiser usar em outros computadores, guarde-a num lugar seguro, como um gerenciador de senhas. Não publique nem mande a chave em grupos. Se ela vazar, apague-a em github.com/settings/personal-access-tokens e crie outra.

Sem chave? Publicar manualmente
  1. Toque em Baixar lista de vídeos. O navegador salva um arquivo videos.json na sua pasta de Downloads.
  2. Abra a página de envio de arquivos do GitHub (é preciso entrar com a conta dona do site).
  3. Arraste o videos.json baixado para a página e clique em Commit changes.
Outras opções

Joga fora o que ainda não foi publicado e volta para a lista que está no site.

Esconde os botões de administração neste navegador. Para voltar, abra o site com #/admin no fim do endereço. A chave continua salva.
